# 研途 · Research Notebook

**[打开研途科研工作台](https://chengjiawei-cell.github.io/research-notebook-web/) — 无需安装，直接从浏览器使用。**

大学科研记录工作台的网页界面。通过 GitHub Pages 在线访问，支持课题组、日程、时间线、任务进度、科研日志、文献与资料上传。

这个公开界面仓库不包含任何真实科研记录和资料。记录默认保存在当前浏览器；在网站设置中连接自己的私有 GitHub 仓库后，可以跨设备同步。

文献模块支持 PDF 与笔记并排阅读、选中文字摘录、段落翻译、阅读页码恢复和笔记导出。笔记草稿自动保存在本设备，点击保存后写入文献记录。可从本机打开 PDF，也可关联课题组资料库中的 PDF。

翻译提供 MyMemory 在线服务，以及浏览器支持时的本机翻译。在线模式只发送本次待翻译的文字，个人笔记、整份 PDF 与 GitHub 令牌均不会发送。

访问令牌仅保留在当前页面内存中，不写入网站代码、浏览器数据库或导出的记录。私有仓库的连接窗口提供最小权限说明。

网页源码位于 `public/`，使用 `npm run build` 生成发布包；发布只包含明确列出的界面资源。
